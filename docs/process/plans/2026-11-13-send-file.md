# send_file Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an MCP tool `send_file` that sends one local file from an allowed folder to a chat as photo, document, audio, voice, video or video_note.

**Architecture:** A new pure-Go package `internal/probe` reads format and metadata from file headers (no decoding, no external tools). `internal/tg` gets the allowed-folder check, a pure `buildMedia` step that turns (kind, file) into Telegram media fields, and `Service.SendFile`, which uploads with gotd's `uploader` and calls `messages.sendMedia`. `internal/mcpserver` validates input and registers the tool; `config` and `serve` add two env vars.

**Tech Stack:** Go 1.25, gotd/td v0.163.0 (`telegram/uploader`, `tg`, `telegram/message/unpack`, `telegram/message/markdown`), modelcontextprotocol/go-sdk, `tgmock` for tests.

**Spec:** `docs/process/specs/2026-11-13-send-file-design.md`

## Global Constraints

- No cgo, no external programs, no new module dependency. Readers are hand-written.
- Kinds, exactly: `photo`, `document`, `audio`, `voice`, `video`, `video_note`.
- Env vars: `TELEGRAM_MCP_SEND_DIRS` (list split by `os.PathListSeparator`, default = download folder), `TELEGRAM_MCP_MAX_UPLOAD_MB` (positive int, default `100`).
- All path and format checks run before any Telegram call.
- Format detection uses file content, never the extension.
- Error strings are copied verbatim from the spec (listed in Task 6 and Task 7).
- Tests use synthetic headers built in Go (package `internal/probe/probetest`), not binary fixtures: local ffmpeg is broken and the readers parse headers only.
- `go test ./...` and `go vet ./...` pass before every commit. Work only in `.claude/worktrees/send-file`.

## Review Focus

1. **MP4 with `moov` after `mdat`** (the ffmpeg default without `+faststart`). Must parse. Test in Task 2.
2. **An allowed folder that is itself a symlink** (macOS `/tmp` → `/private/tmp`). `/tmp/x.ogg` with `TELEGRAM_MCP_SEND_DIRS=/tmp` must be accepted. Test in Task 5.
3. **A phone video with a 90° rotation matrix.** `video` must report displayed width and height (swapped). Test in Task 2.
4. **An audio-only MP4/M4A sent as `video` or `video_note`.** Must fail with the `needs MP4 with H.264` error, not a crash or a zero-size video. Test in Task 6.
5. **Whitespace-only caption.** Treated as no caption. For `video_note` it must not trigger `video_note cannot have a caption`. Test in Task 8.

Exact rules and errors (copy verbatim):

| kind | spec |
| --- | --- |
| photo | `ImageFormat` ok → `Photo: true`. Else `photo needs JPEG, PNG or WebP; send it as document instead` |
| document | always ok. MIME from `mime.TypeByExtension(filepath.Ext(name))` with parameters stripped (`mime.ParseMediaType`), else `application/octet-stream`. `ForceFile: true`. Attributes: `DocumentAttributeFilename{name}` |
| audio | `Audio` ok → MIME by format: mp3 `audio/mpeg`, m4a `audio/mp4`, ogg `audio/ogg`, flac `audio/flac`. Attributes: `DocumentAttributeAudio{Duration: round(d)}`, `DocumentAttributeFilename{name}`. Else `audio needs MP3, M4A, OGG or FLAC; send it as document instead` |
| voice | `Ogg` with Codec `opus` → MIME `audio/ogg`, `DocumentAttributeAudio{Voice: true, Duration: max(1, round(d))}`. Else `voice needs OGG/Opus; convert with: ffmpeg -i <in> -c:a libopus -b:a 32k out.ogg` |
| video | `MP4` with VideoCodec `avc1` or `avc3`, AudioCodec `""` or `mp4a` → MIME `video/mp4`, `DocumentAttributeVideo{SupportsStreaming: true, Duration: d, W, H}`, `DocumentAttributeFilename{name}`. Else `video needs MP4 with H.264; convert with: ffmpeg -i <in> -c:v libx264 -c:a aac out.mp4` |
| video_note | same MP4 check (error prefix `video_note`). Then W≠H → `video_note must be square, got WxH; crop with: ffmpeg -i in.mp4 -vf "crop='min(iw,ih)':'min(iw,ih)',scale=384:384" -c:v libx264 -c:a aac out.mp4`. Then round(d) > 60 → `video_note is N s, limit is 60 s` (N = round(d)). OK → MIME `video/mp4`, `DocumentAttributeVideo{RoundMessage: true, Duration: d, W, H}` |

`<in>` stays literal, as in the spec.
